# 003 MVP Implementation 需求说明

> 文档状态：Approved  
> 创建日期：2026-09-05  
> 继承需求：V1.1（001-foundation）  
> 上一迭代：002-technology-selection

## 1. 目标

初始化可在 IDEA 与 VS Code 中独立启动并联调的前后端工程，交付多用户博客首期 MVP：账号、资料、内容、四级权限、分类标签、搜索、媒体、互动、通知、站点配置、统计和基础管理闭环。

## 2. 实现范围

- 邮箱注册、开发环境验证码查询、登录、退出、当前用户、修改密码和密码重置。
- 用户资料维护与公开个人主页。
- 博客/笔记草稿、编辑、预览、发布、下线和逻辑删除。
- 公开、登录可见、指定用户可见和仅自己可见四级访问控制。
- 分类、标签、归档、首页列表和中英混合基础搜索。
- 头像、封面和正文图片上传及受控读取。
- 点赞幂等、评论、回复、删除/隐藏、评论开关和站内通知。
- 关于、友情链接、站点配置、用户统计和基础平台管理 API。
- 公共前台、用户中心和管理端的可操作页面骨架及核心流程。
- PostgreSQL 18、Mailpit、本地媒体卷、CI、Dependabot 和容器构建基线。

## 3. 默认产品规则

- 注册使用唯一用户名、唯一邮箱和密码；本地开发通过邮件捕获器查看验证码。
- 指定用户授权通过精确用户名添加；作者始终可访问本人未删除内容。
- 允许作者点赞自己的博客，同一用户对同一内容最多一个有效点赞。
- 评论数据允许任意父子关系，首期界面按根评论加回复列表展示。
- 互动通知只做站内通知，不发送互动邮件。
- 用户删除评论后保留占位，以维持回复上下文；管理员和作者可隐藏评论。
- 内容及媒体使用逻辑删除；永久清理和账号注销留待上线合规迭代。
- 首期站点只有一个平台管理员，使用数据库角色区分，不设置独立管理员账号系统。

## 4. 验收标准

- backend 可由 IDEA 或 Maven Wrapper 在 8080 端口启动。
- frontend 可由 VS Code 和 pnpm 在 3000 端口启动，并将 /api 代理到后端。
- Docker Compose 可启动 PostgreSQL 18 和 Mailpit，且不占用本机 PostgreSQL 16 的 5432 端口。
- 核心用户流程可从浏览器完成，服务端权限测试覆盖跨账号和四级可见性。
- 后端测试、前端检查与生产构建通过。
- 变更提交到 dev 并推送到 origin/dev。

## 5. 本期不做

- 不实现第三方登录、双因素认证、定时发布、版本历史、账号注销或数据导出。
- 不引入 Redis、MinIO、独立搜索引擎、消息队列、微服务或 Kubernetes。
- 不执行生产服务器部署，不配置真实域名和真实 SMTP 密钥。
