# 003 MVP Implementation 决策记录

> 文档状态：Approved  
> 更新日期：2026-09-05

## DEC-017：通过用户名维护指定用户授权

- 状态：Accepted
- 决策：作者通过精确用户名搜索并添加授权用户，不使用匿名邀请链接。
- 原因：授权对象始终是已验证的平台账号，撤销和审计边界明确。

## DEC-018：评论数据保留完整父子关系

- 状态：Accepted
- 决策：数据库保存根评论、父评论和被回复用户；删除正文后保留占位，界面首期按根评论和回复列表展示。
- 原因：避免固定层级破坏上下文，同时控制首期界面复杂度。

## DEC-019：管理员复用普通认证系统

- 状态：Accepted
- 决策：管理员与普通用户共用 Session 认证，通过角色授权管理 API；首个管理员通过开发种子配置创建。
- 原因：避免两套身份系统产生重复安全逻辑。

## DEC-020：本迭代交付可运行 MVP，不部署生产环境

- 状态：Accepted
- 决策：交付本地开发、自动化测试和生产镜像基线；域名、真实 SMTP、备份恢复和生产发布另设上线迭代。
- 原因：本期先验证完整业务和权限闭环。
